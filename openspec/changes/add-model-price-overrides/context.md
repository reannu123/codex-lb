# Phase 3 pricing audit

## GPT-6.2 Sol evidence

The orchestrator supplied sanitized counts from a production snapshot. It contained 4,702 exact `gpt-6.2-sol` request rows out of 30,398. All 4,702 stored `cost_usd = NULL`. Of those, 4,605 had input, output, and cached-input token fields present, and 97 lacked those fields. No other allowlisted alias matched in the supplied evidence.

At checkout `72630bbf`, the bundled snapshot dated 2026-10-16 has 103 models and the offline active map has 113 entries after built-in defaults. Neither contains `gpt-6.2-sol`. An isolated local run exercised the checkout's real bundle loader, resolver, and request-log calculation with synthetic usage (1,000 input, 100 cached, 100 output) and stubbed unrelated imports. The exact ID, uppercase equivalent, synthetic dated ID, and bare `gpt-6.2` each returned no price and a NULL estimate. The same input priced `gpt-6.1-sol` at $0.00281 and `gpt-6-sol` at $0.00282. Their base rates are 2 / 0.1 / 10 and 2 / 0.2 / 10 USD per million, respectively. The old bare `gpt-5.6` alias resolved to `gpt-5.6-sol` at 4 / 0.4 / 20. Those prices are controls and supply no price for GPT-6.2 Sol.

The repository's request-log write leaves cost NULL when usage exists but price resolution fails. The request-log mapper calls the breakdown helper and the recent-requests table renders a null cost as `--` via `formatCurrency`. This reproduces the observed symptom and makes an unresolved rate the supported explanation for the token-complete cohort under the checked catalog. The aggregate rules out recorded zero and display rounding for that cohort. The 97 other rows also lack usage. The deployed image revision, live/cache contents at request time, and tier/source splits were absent from the aggregate. The audit confirms the offline gap and stored missing costs, without attributing the production gap to a particular catalog supplier, rejection, or refresh failure.

## Existing paths

| Area | Observed behavior |
| --- | --- |
| Resolution | `app/core/usage/pricing.py` tries case-insensitive exact ID, then a recognized base for `-YYYY-MM-DD`, then longest matching built-in glob. Unrecognized GPT-5 minor families cannot inherit the broad GPT-5 price. No GPT-6 family alias supplies GPT-6.2 prices. Routing/model visibility is separate from price resolution. |
| Catalog and restart | `app/core/usage/pricing_catalog.py` starts with built-ins underneath the bundled snapshot. `metadata_scheduler.py` restores a valid `pricing-cache.json` in the app data directory. A newer bundle wins overlaps against an older disk cache, retaining valid non-overlaps. Refresh tries validated OpenAI text prices from models.dev, then LiteLLM for absent models and compatible optional fields. Compatibility considers the base triple, threshold, and overlapping fields. Refresh folds over last-good prices and persists the merged snapshot. Invalid input or outages retain usable fallback prices. Runtime refresh is hourly after success and retries failures after five minutes. Snapshot v1 records a global source URL list and timestamp, without reliable per-model origins. The process-local catalog refresh is distinct from shared database cache invalidation. |
| Tier | Reservation uses the post-policy request tier and estimated tokens. Subscription finalization normally uses the upstream-reported tier when available, falling back to the request tier. The calculator checks a strict input-token threshold, then a complete matching tier-specific long-context group, explicit Priority (including Fast), Priority multiplier, explicit Flex (with existing long-context multipliers when applicable), standard long-context, then base. An absent cached rate inherits the chosen input rate. Zero remains a real rate. |
| Budget | `app/modules/api_keys/service.py` computes a conservative token-scaled unknown-model hold for an estimate at or below zero, then settles with integer microdollars. The isolated reproduction of its source function returned 0 for unresolved GPT-6.2 Sol. It also returns 0 for unrated usage, known zero, and positive amounts under a microdollar after truncation. Cost is settled separately from request-log USD, and display-only changes cannot fix budget accounting. Direct usage recording has a separate entry point. |
| Request logs and reports | Subscription insertion computes an unrounded cost in `app/modules/request_logs/repository.py`. The mapper currently rounds to six decimals and may compute components or fill a display-only NULL total from current prices. A stored total wins. Aggregates generally sum persisted costs and can coalesce all-missing results to numeric zero. The image route has a separate same-request host-to-public-model relabel/reprice step before folding. Configured Model Sources have separate rates and some dispatch paths presently coerce missing source cost to zero. |
| Repair | The leader's startup/runtime backfill scans eligible retained NULL subscription rows in batches of 200. It can restart from zero or rescan when refresh changes the catalog. It updates eligible folded aggregates under the fold-state lock without changing prior non-NULL estimates, counts, or settled limit ledgers. The older Alembic cost migration also computes prior costs using a pricing helper. |
| Settings | `/api/settings` requires a dashboard session and uses dashboard error formatting. The model context-window collection uses a model-keyed repository, dashboard write permission, audit events, a local cache clear, and a shared DB invalidation signal. The cache poller refreshes peers asynchronously. A settings response alone does not prove a peer has seen a mutation. |

## Example

With hypothetical local `2 / 0 / 8` USD per million on the exact `gpt-6.2-sol` ID, 1,000 input tokens including 100 cached and 100 output cost $0.0026 at standard rates. A request whose usage is entirely cached can legitimately cost $0 under that override. One input token at a hypothetical input rate of $0.10 per million costs $0.0000001 and should be displayed as a small positive amount even if its settled integer microdollars equal zero. These figures are illustrative and supply no upstream prices.
